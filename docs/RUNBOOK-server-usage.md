# 服务端使用观测（无需电脑采集器）

## 功能与证据边界

入口：后台「使用观测」(`/usage`)，或「订阅管理」页面的同名按钮。

「优选状态」页签复用现有只读 API，按节点展示后台维护开关、暂停状态、运营商缺测、测点最近检测、发布版本、历史候选延迟、配置异常和预算保护。查看不调用新探针；已发布记录不等于当前有效下发清单，测点延迟不等于客户端延迟。

- 只覆盖本面板托管、受 CF 保护的 Xray VLESS + WS + TLS 节点。外部节点及其他协议不修改。
- 授权身份来自订阅所有者或面板内的分享接收者；同一订阅链接给多人使用，仍只能识别为一个身份，不是人数或设备数。
- 每个授权版本、节点、CF 候选配置分配独立 UUID。候选 IP、端口、运营商档案或认证配置变化会生成新身份；改名称不会生成新身份。
- 源站认证身份的流量增长证明此凭据在节点被使用。它不能独立证明客户端实际拨入哪个 CF Anycast IP、实际运营商、地域、浏览网站或有人正在操作。客户端修改候选 IP 后仍可使用同一凭据。
- 健康检查、自动测速也可能产生流量。未到达源站的失败/timeout、端到端时延及连接总数不在本功能观测范围。
- 不采集源 IP、目标网站、URL、进程名或用户设备信息。不增加电脑软件、Worker 或付费云探针；不改变 CF 探针原有预算。

UI 借鉴 [PatternFly dashboard](https://www.patternfly.org/patterns/dashboard/) 的总览/详情层次和 [Carbon dashboard](https://v10.carbondesignsystem.com/data-visualization/dashboards/) 的信息密度原则，沿用工程 Ant Design 主题。包括桌面表格、移动端卡片、明暗主题、搜索/筛选、证据抽屉、趋势、覆盖与异常状态。状态同时使用文字与颜色，不单靠颜色表达。

## 上线前置条件

本功能默认关闭。合并代码或发布 Agent 不代表生产观测已启用。

1. 备份数据库、部署版本和目标节点配置。运行现有发布检查；应用增量迁移 `20261031120000_server_usage`，不得重建数据库。
2. 发布面板与服务器 Agent 1.8.0+，先验证原心跳、节点状态、链式服务和公网代理没有退化。
3. 节点的 Xray 必须支持 `HandlerService`、`api inbounduser`、`api adu` 和 `api rmu`。本地原生基准为 Xray 26.2.6；其他版本必须逐台预检，不能由版本号猜测兼容性。不得自动升级共享 Xray 二进制。
4. 保留统计端口只监听 `127.0.0.1`，不开放公网统计端口。节点远端资源归属清单和配置哈希必须与本面板一致；发生漂移时停止，不能强行接管。
5. 明确分享接收者知悉授权身份的聚合使用观测。需要区分用户时使用面板分享，不共用所有者链接。
6. 在面板服务环境设置 `USAGE_OBSERVATION_ENABLED=true` 并按既有方式重启面板服务。该开关不重启代理节点。

## 小范围接入与验收

1. 「使用观测 → 接入与覆盖」开启一个订阅。系统预生成当前所有者、分享接收者及有效 CF 候选的身份；尚未完成节点验证时继续下发原 CDN 凭据。
2. 在维护窗口点击一个节点的「准备节点」。首次需添加用户统计策略，可能重启此节点；弹窗必须明确确认。配置先做原生校验、持久化和归属登记，再启动并逐个读取运行 UUID 验证。失败尝试还原原配置和归属；若回退不能验证，会明确显示 `ROLLBACK_FAILED`，不能宣称无影响。
3. 之后自动同步每分钟最多处理 5 个已准备节点，按上次同步时间轮转。只能热添加/移除身份，不能在后台自动重启节点。可点击「同步凭据」立即对账。全局多实例部署由现有数据库锁串行保护同一节点。
4. 当凭据持久化和运行验证都通过，用户在现有客户端更新订阅或 CF provider。主链接、分享链接、SNI、WS Host、TLS 校验和 CDN 保护不变。候选为空仍遵循原有拒绝/清空 provider 行为，绝不直连源站。
5. 使用两个分享身份分别访问一个可控测试目标，确认身份、节点和候选配置分别归因；旧配置继续可用且仅显示旧共享凭据汇总。停止流量后应转为「暂无近期流量」，停止上报超过 90 秒应转为「数据待更新」，速率显示未知而不是零。
6. 验证客户端更新前后、新旧身份、面板外网访问及未接入节点；保存真实客户端和服务端证据后才扩大范围。本地 fixture 不代替该验收。

## 暂停、撤销与回退

- **暂停一个订阅**：停止为该订阅下发新的观测身份和保存新的身份采样；已导入的身份仍可用。该节点所有订阅均暂停后，下一次成功心跳不再请求身份采样。其他订阅共用节点时仍有节点级采集，暂停订阅的数据不入库。
- **撤销分享/轮换 token/删除订阅/移出节点**：后台识别失效授权并删除其独立服务端身份，远端验证通过后才标记已移除。SSH 不通会延迟；已有长连接可能继续至断开，不能宣称即时踢下线。
- **旧共享 UUID 仍保留**：这是兼容性约束。撤销独立身份不代表历史共享凭据同时失效；本期不承诺逐用户彻底封禁。退役旧 UUID 必须另行安排客户端迁移和维护窗口。
- **全局紧急暂停**：将 `USAGE_OBSERVATION_ENABLED=false` 并重启面板。停止新身份发布、采样入库和自动 SSH 对账；保留数据库、已部署用户、旧 UUID 和现有转发。此时远端撤销也暂停，因此不能把全局开关当作封禁工具。
- **代码回退**：优先关闭开关并保留新增表/列和远端身份配置。旧面板可读取增量数据库，旧 Agent 忽略新指令。旧版面板的节点重部署可能丢弃独立身份，回退期间禁止用旧代码重部署已接入节点，直到所有客户端迁回旧凭据或已验证保留身份的兼容配置。
- **准备失败**：新 UUID 不进入订阅。热同步部分失败时保留有效的目标持久化配置，待下次幂等重试；不为恢复观测而重启代理。首次准备备份留在受保护配置目录中，含凭据，不能贴入工单或聊天；验收后按既有备份政策管理。
- 不自动删除表、清空认证身份或覆盖未知远端配置。需要恢复远端配置时，同时核对服务归属、配置内容、运行用户和实际代理连通性。

## 指标和资源上限

- Agent 约每 10 秒心跳；采样在心跳发送路径之外异步执行。每批最多 20 个节点，超过时轮转；并发 4、总时限 8 秒、每节点 2 秒、gRPC 响应最多 1 MiB。大规模轮转可能超过新鲜窗口，UI 如实显示待更新。
- 每个节点最多 500 个未确认移除的独立身份，另有一个 `np-legacy`。达到上限的新增候选保留原 CDN 凭据并显示保护上限，不偷偷复用错误身份。旧候选不会仅因短期未活动被删除，以免破坏缓存客户端；容量需运营人员监控。
- 近 60 秒有可靠正向流量增量为「近期有流量」；90 秒内成功采样为新鲜。首次计数、计数回绕、内核重启、断采样区间仅建立新基线，不补造活动或历史流量。
- 采样按服务器归属校验，拒绝重复、乱序、越界时钟和未知字段；上报故障不影响代理转发。异常观测入库不会阻断普通心跳处理。
- 入库为有界异步处理，同一面板进程最多同时处理 8 台服务器、每台最多一个批次；过载时丢弃新观测批次而不排无限队列。页面保持真实的新鲜度，不把丢样补成零流量。面板回退拒绝观测扩展字段时，Agent 仅在 400/413 后向同一地址重发一次不含扩展的普通心跳，不绕过认证失败。
- 流量按小时汇总保留 30 天，详情展示近 7 天。图表空缺不表示零流量，不用于计费。已验证移除的身份墓碑保留 30 天；仍有效身份保留以维持已有客户端。
- 总览最多 1,000 条身份，优先最近有活动的记录，超限显示提示且汇总仅覆盖展示范围；移动端最多展示筛选结果前 100 条。每 15 秒前台刷新，趋势按需加载；刷新不调用 CF 测速。

## 本地验证

完整门禁仅使用隔离 PostgreSQL、合成浏览器 API 和 loopback 代理，不需要生产密钥：

```sh
PG_BIN=/path/to/postgresql/bin \
XRAY_BINARY=/path/to/verified/xray \
GO_BINARY=/path/to/go \
bash scripts/ci/verify.sh
```

此外需安装工程依赖、sing-box、openssl、curl、Python Playwright/Chromium。CI 使用校验和固定的 [Xray 26.2.6](https://github.com/XTLS/Xray-core/releases/tag/v26.2.6)；原生 fixture 真实验证 TLS + VLESS + WS、独立用户热更新、流量归因、重启持久化及 Go gRPC 解码。

测试定位：

- `apps/server/src/usage/*.spec.ts`：输入、权限、运行 UUID 发布门禁、确认及回退。
- `scripts/tests/usage-pg.fixture.mjs`：真实事务、并发去重、隔离、基线/增量、暂停及撤销。
- `scripts/tests/usage-native.test.mjs`、`apps/agent/usage_stats_test.go`：原生 loopback 转发、统计、轮转和数据白名单。
- `scripts/tests/usage-browser.py`：桌面/手机、明暗主题、证据、趋势、筛选、取消无副作用、暂停和错误状态。截图位于 `out/ci/usage-*.png`，均为合成数据。

实现完成不等于已发布：生产数据库迁移、Agent 分批升级、首次节点准备及真实 CDN/客户端验收需单独执行。
